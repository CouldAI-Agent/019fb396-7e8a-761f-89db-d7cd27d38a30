# Same Answer Puzzle

A Flutter application demonstrating the concept of "different solving powers leading to the same answer". This app presents a mathematical puzzle where users are given a target number and must identify various mathematical expressions (addition, subtraction, multiplication) that all evaluate to the same target result, despite using entirely different operations and numbers.

## Features
- **Dynamic Puzzle Generation:** Randomly generates target numbers and corresponding valid/invalid math equations.
- **Multiple Approaches:** Mixes addition, subtraction, and multiplication paths to reach the same conclusion.
- **Responsive Design:** Adapts fluidly between mobile, tablet, and web views.
- **Scoring System:** Rewards correct selections and penalizes incorrect guesses.

## Tech Stack
- Flutter (Dart)
- Material 3 Design

## Setup
1. Ensure you have Flutter installed.
2. Run `flutter pub get` to fetch dependencies.
3. Start the app using `flutter run`.
